## 版本记录

### v1.2.5 (2026-11-02)
- 新增：过滤 DJ、Remix、伴奏、翻唱、Cover、Live、现场、加速、串烧、合唱、Type Beat 等二改版本
- 新增：括号里带「版」字的一律过滤（女声版、深情版、欢快律动版等）
- 新增：多歌手合唱（& 、分隔）自动过滤
- 新增：搜索时歌名或歌手任一对上即保留，不再硬拆歌手名
- 新增：结果按「标题完全匹配 > 歌手匹配 > 源可靠度」排序，正版原唱排第一
- 修复：6uq 打坏时能自动回落到网易云等补充源
- 保留：封面（6uq/酷我图床）、歌词（6uq + 网易云）

## 说明

只保留正版原唱，翻唱和二改全部过滤。
